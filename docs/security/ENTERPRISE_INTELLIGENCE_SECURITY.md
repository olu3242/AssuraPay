# Enterprise Intelligence Security

Every record is workspace-scoped and backed by RLS contracts. Both composite indices apply a hard override — a failed mandatory gate or an active dispute hold forces the score to zero regardless of every other factor, so no dashboard built on these indices can present a passing picture over a real blocker. Executive Dashboard snapshots are filtered to a role's allowed widgets **before** persistence, not at render time — a stored snapshot never contains a widget the requesting role wasn't explicitly granted. Predictive Execution Intelligence forecasts are advisory only: a forecast can only be produced through the governed `ForecastGateway`, confidence is validated on every call, and every forecast starts `NOT_REVIEWED` — nothing in this package can act on a forecast without an explicit human accept or reject.
