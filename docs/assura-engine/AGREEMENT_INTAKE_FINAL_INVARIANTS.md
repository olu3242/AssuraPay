# Final invariants

- Three intake paths, one canonical Agreement.
- Extraction is proposal, never acceptance.
- Missing terms are clarified, never invented.
- Artifact/document claims retain provenance.
- Canonical creation precedes intake conversion state.
- Conversion is idempotent and failure-atomic.
- Workspace/tenant authority is server-derived and RLS-backed.
- Intake cannot activate, certify, authorize release or execute payment.
- Existing downstream Agreement/Performance/Evidence/Payment governance remains authoritative.
- Production readiness requires executable CI/live proof.
