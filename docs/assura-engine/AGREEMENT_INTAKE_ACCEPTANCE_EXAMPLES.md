# Acceptance examples

DIRECT: “Replace my roof for $18,000” -> gaps for parties/currency/payment terms as needed -> resolve -> canonical agreement.

INFORMAL: quote/invoice/proposal/messages -> extracted terms cite source artifact/section -> unresolved ambiguity blocks conversion -> canonical agreement after review.

FORMAL: contract/SOW -> extracted operational terms retain document provenance -> no silent rewrite/acceptance -> canonical agreement after review.

All three continue through the existing negotiation/approval/signature/activation and downstream performance assurance lifecycle.
