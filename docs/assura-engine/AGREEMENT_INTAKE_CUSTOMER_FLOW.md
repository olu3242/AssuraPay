# Customer flow

Start agreement -> choose Create from scratch / Use what you already have / Upload a contract -> AssuraPay proposes a structured agreement -> user reviews source-backed terms -> missing/ambiguous terms are resolved -> send/review through existing counterparty proposal process -> mutual agreement -> existing activation boundary -> perform -> evidence -> verify -> approve when required -> pay.

Customer language: `Tell us the deal. Agree together. Do the work. Prove it. Get paid.`

The product must not promise that generated text is legal advice or that an extracted contract is automatically accepted/enforceable. High-risk/jurisdiction-specific legal questions can require professional review.
