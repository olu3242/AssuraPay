# Performance Blueprint Architecture

`@assurapay/performance-blueprint` transforms one published Agreement Intelligence version into a source-grounded operational plan. A blueprint cannot publish until it has validated scope, deliverables, milestones, and a published Definition of Done for every deliverable.

The package owns planning authority; Governance Core continues to own runtime execution. Published versions are immutable and superseding versions preserve history. Planned money values use integer minor units and are allocations only—not payment authorizations or transfers.

Live PostgreSQL RLS execution and downstream activation into runtime execution remain deployment/integration gates.
