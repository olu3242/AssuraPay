# Completion Assurance Security

Every record is workspace-scoped and backed by RLS contracts. A reinspection is unreachable unless the referenced inspection completed and failed, closing off any path to a paper reinspection of already-passing work. An issue cannot resolve without an independently verified corrective action plan, and the blocker query is the only signal Engine 40 trusts for outstanding risk. Change requests require a rationale on every decision and cannot implement without prior approval. Acceptance decisions are never overwritten — a new decision supersedes the prior one and both remain on the record. A completion certificate cannot be issued unless the quality gate passed, the inspection passed, no blocking issues remain open, and the referenced acceptance decision is active and non-rejecting; at most one certified certificate can exist per work item, and revocation always requires a reason.
